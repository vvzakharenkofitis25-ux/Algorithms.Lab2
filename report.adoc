== Мета роботи
Дослідити на практиці компроміс між часовою (Time Complexity) та просторовою (Space Complexity) складністю алгоритмів на прикладі обчислення чисел Фібоначчі (Варіант 2), а також вивчити принципи роботи поліноміального хешування методом Горнера та оцінити якість розподілу функцій через підрахунок колізій.

== Частина 1: Обчислення чисел Фібоначчі

=== Опис підходів до реалізації
1. **Наївна рекурсія (Рівень 1):** Обчислення за класичною формулою `fib(n-1) + fib(n-2)`. Має експоненційну часову складність через багаторазове дублювання обчислень для тих самих значень.
2. **Мемоізація (Рівень 2):** Рекурсивний підхід, який використовує додатковий масив для збереження вже знайдених чисел. Це дозволяє уникнути повторних обчислень за рахунок додаткової пам'яті.
3. **Ітеративний підхід (Рівень 3):** Циклічний алгоритм, що крок за кроком обчислює наступне число, утримуючи в пам'яті лише два попередні значення.

=== Порівняльна таблиця результатів
[cols="1,1,1,1,1", options="header"]
|===
| Підхід | Теоретичний час | Теоретична пам'ять | Фактичний час (нс) | Фактична пам'ять (байт)
| Наївна рекурсія (N=40) | O(2^N) | O(N) | 414086300 | 0
| Мемоізація (N=50) | O(N) | O(N) | 13500 | 0
| Ітеративний підхід (N=50) | O(N) | O(1) | 8600 | 0
|===

== Частина 2: Поліноміальне хешування

=== Опис алгоритму
Для аналізу розподілу даних було реалізовано метод Горнера для обчислення поліноміального хешу рядка:
[latex]
\$H(S) = (S[0] \cdot P^{L-1} + S[1] \cdot P^{L-2} + \dots + S[L-1]) \pmod M\$

=== Результати тестування хешування
* **Кількість генерованих слів:** 1000
* **Параметри функції:** константа множника P = 31, розмір таблиці M = 997
* **Кількість зафіксованих колізій:** 381

== Висновок
Під час виконання лабораторної роботи було підтверджено теоретичні оцінки складності алгоритмів:
1. **Наївна рекурсія** продемонструвала критично низьку швидкість роботи (понад 414 млн наносекунд) навіть для відносно малого значення N=40 через складність $O(2^N)$.
2. **Мемоізація та Ітеративний підхід** показали колосальний приріст продуктивності (працюють у десятки тисяч разів швидше), оскільки зводять складність до лінійної $O(N)$. При цьому ітеративний підхід є найбільш оптимальним компромісом, адже не потребує виділення динамічного масиву.
3. **Частина 2** наочно продемонструвала природу виникнення колізій (381 колізія на 1000 слів) при обмеженому розмірі хеш-таблиці (M=997), що є природним для простих методів хешування.re
